# Windows Terminal

Copy the object in `deliverator-signal.json` into the `schemes` array of your existing settings JSON. Do not replace the whole settings file. In the profile you want to preview, set:

```json
"colorScheme": "The Deliverator — Signal study"
```

Alternatively, use Windows Terminal’s color-scheme editor and enter the generated values. Restore the profile’s previous scheme to switch back.

JSON and all 16 ANSI assignments are cross-checked with the other terminal exports. Full Windows Terminal visual acceptance remains open.
