# TextMate

Open `Deliverator-Signal.tmTheme` in TextMate and select **The Deliverator — Signal study** in its theme chooser. Import UI varies by application/version; this is a standard XML-plist tmTheme file, not a TextMate bundle.

Select your previous theme to switch back. The file is parsed and cross-checked with the bat export. Actual TextMate rendering and installation are awaiting acceptance.
