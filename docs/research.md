# Reference study

These projects are useful models for documentation and distribution. Their words, visual assets and color files were not copied. This is a selected reference set, not a claim to have ranked every theme project.

## Catppuccin

[Repository](https://github.com/catppuccin/catppuccin) · [Website](https://catppuccin.com/) · [Port creation](https://github.com/catppuccin/catppuccin/blob/main/docs/port-creation.md)

Keep the palette easy to inspect, make application discovery immediate, and give prospective port authors a clear path. The Deliverator starts with one recipe and a small honest port table, rather than borrowing an established project’s breadth or social proof.

## Tokyo Night

[Repository and extras](https://github.com/folke/tokyonight.nvim)

Treat exports as generated artifacts of one color system. Put installable files where users can find them, and separate application setup from palette definition. The Deliverator’s deterministic builder and drift check adopt this maintenance principle, with independently authored mappings.

## Rosé Pine

[Theme repository](https://github.com/rose-pine/rose-pine-theme) · [Website](https://rosepinetheme.com/)

A concise, recognizable identity can carry across many programs. Describe the atmosphere and semantic roles before listing implementation details. Here the identity is blue-black material plus charged yellow-green; the prose should stay equally direct.

## Nord

[Repository](https://github.com/nordtheme/nord) · [Colors and palettes](https://www.nordtheme.com/docs/colors-and-palettes/)

Explain what groups of colors mean. Document relationships so a new port preserves the system instead of distributing attractive but arbitrary swatches. The Deliverator exposes its coordinate recipe and contrast evidence alongside the generated colors.

## Source and format references

- [Snow Crash, chapter-one primary text](https://chnm.gmu.edu/exploring/20thcentury/consumerism/pop_stephenson1.html): conceptual inspiration; no book artwork is reproduced.
- [Björn Ottosson’s Oklab definition](https://bottosson.github.io/posts/oklab/) and [CSS Color 4](https://www.w3.org/TR/css-color-4/#ok-lab): conversion and perceptual coordinates.
- [VS Code color-theme guide](https://code.visualstudio.com/api/extension-guides/color-theme): workbench and syntax/semantic token structure.
- [Neovim API](https://neovim.io/doc/user/api.html#nvim_set_hl()): highlight definitions.
- [bat custom themes](https://github.com/sharkdp/bat#adding-new-themes): tmTheme import and cache behavior.
- [Alacritty configuration](https://alacritty.org/config-alacritty.html#colors), [Windows Terminal schemes](https://learn.microsoft.com/en-us/windows/terminal/customize-settings/color-schemes), [Kitty configuration](https://sw.kovidgoyal.net/kitty/conf/), and [WezTerm color schemes](https://wezterm.org/config/appearance.html): terminal formats.
